# Исправление стартового экрана

Замените только `js/app.js`.

Исправлена маршрутизация рендера: главная страница теперь снова открывается через обычный стартовый экран, а специальный рендер остаётся только для разделов «Тачки» и «Колесо фортуны». Это возвращает главную страницу и её фон, не меняя механику колеса.
