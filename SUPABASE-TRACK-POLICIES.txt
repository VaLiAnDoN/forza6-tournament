НАСТРОЙКА ФОТОГРАФИЙ ТРАСС

1. Supabase -> Storage -> Forza Photo. Бакет должен быть Public; в Storage -> Buckets -> Forza Photo -> Edit bucket установите лимит не менее 20 MB и разрешённые MIME image/jpeg, image/png, image/webp. Лимит проекта Storage тоже должен быть не ниже 20 MB.
2. Supabase -> SQL Editor -> New query: вставьте весь запрос ниже и нажмите Run. Его можно запускать повторно.
   Без этих правил загрузка фото вернёт ошибку 400 (в тексте: "row-level security policy").

drop policy if exists "Forza Photo public select" on storage.objects;
drop policy if exists "Forza Photo public insert" on storage.objects;
drop policy if exists "Forza Photo public update" on storage.objects;
drop policy if exists "Forza Photo public delete" on storage.objects;

create policy "Forza Photo public select" on storage.objects for select to anon using (bucket_id = 'Forza Photo');
create policy "Forza Photo public insert" on storage.objects for insert to anon with check (bucket_id = 'Forza Photo');
create policy "Forza Photo public update" on storage.objects for update to anon using (bucket_id = 'Forza Photo') with check (bucket_id = 'Forza Photo');
create policy "Forza Photo public delete" on storage.objects for delete to anon using (bucket_id = 'Forza Photo');

Права открыты всем, кто знает адрес сайта (сайт без отдельной авторизации в Supabase).
