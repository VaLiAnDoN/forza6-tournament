Первый этап: архив только для просмотра. Скопируйте index.html, history.css и папку js в корень сайта с заменой index.html и сохранением остальных файлов. Два новых файла js/history.js и js/history-data.js не изменяют состояние турнира и систему достижений. Данные архивов не добавляются в статистику или достижения. Перед заменой index.html сравните с актуальным, если он изменялся после архива пользователя: при необходимости добавьте только строку CSS в head и два скрипта после js/app.js. После публикации обновите страницу с очисткой кеша. У третьего турнира в последней гонке время Влада отсутствует; очки отображены по исходной таблице. Порядок гонок второго турнира в таблице и расписании отличается.
