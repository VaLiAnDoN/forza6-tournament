# Forza Horizon 6 · турнирный сайт

Сайт для компании друзей: чемпионаты, «Тачки», «Колесо Фортуны», список машин и личная статистика.
Чистый HTML/CSS/JS без сборки: работает на GitHub Pages, данные синхронизируются через Supabase.

## Структура

```
index.html        каркас, подключает скрипты по порядку
style.css         все стили
favicon.svg, apple-touch-icon.png, fortune-bg.jpg
img/tachki/       логотип Cars, обработанные фото трека, вырезанные машины персонажей (.webp)
js/
  data.js         константы: дисциплины, трассы, классы, флаги, страны
  core.js         состояние, localStorage, вход по коду
  champ5.js       Чемпионат 5 · Страны: драфт, расписание, очки, вкладки
  events.js       обработчики кликов, ввода и наведения
  map.js          карта мира из точек и подсветка стран
  cars.js         база машин (CARS) и список машин
  wheel.js        колесо рулетки трасс/кругов/погоды и сезона
  stats.js        личная статистика
  tachki.js       турнир «Тачки»: таблица, результаты, вкладки гонок
  tachki-races.js страницы гонок «Тачек»: персонажи, фото трека, окно с машиной
  home.js         меню, главная, «Колесо Фортуны» (игры, драфт дисциплин, рулетка машин)
  fuji.js         фон с Фудзи и переход с сакурой
  sync.js         синхронизация с Supabase (опрос раз в 2 с, слияние правок)
  app.js          фоны, сборка render() и запуск
```

Порядок `<script>` в `index.html` важен: все файлы делят общую область видимости.

## Как добавить новую плитку

1. Создай `js/название.js` с функцией, которая возвращает HTML раздела (как `TACHKI2()` в `tachki.js`).
2. Подключи файл в `index.html` до `app.js`.
3. Добавь плитку в `HOME()` (`home.js`): `data-a="v" data-k="название"`.
4. В `alt()` (`home.js`) добавь `if(view=='название')b=ТВОЯ_ФУНКЦИЯ();`.
5. Данные храни в `S.твоё_поле` и вызывай `save()` после изменений: синхронизация подхватит сама.

## Запуск

Локально: открой `index.html` в браузере (облако будет недоступно без интернета, данные хранятся в localStorage).
На GitHub: Settings → Pages → Branch `main`, папка `/ (root)`.

## Supabase

Таблица `app_state` с одной строкой `id='main'`: поля `rev` (число, растёт при каждом сохранении),
`data` (jsonb со всем состоянием), `updated_at`. Ключ в `sync.js` публичный (`sb_publishable_…`),
поэтому доступ к данным определяют политики RLS в Supabase, а не секретность ключа.

## Безопасность (важно)

Код администратора и коды игроков сейчас лежат в клиентском коде и в общем состоянии.
Для компании друзей это допустимо, но для публичного сайта их стоит хранить в виде хэшей и
проверять функцией на стороне Supabase, а запись ограничить политиками RLS.

## Турнир «Тачки»: как оформить следующую гонку

Данные гонок лежат в `TKR` (`js/tachki-races.js`). Для «Безумной восьмерки» есть поле `chars` (персонажи из `TKC`) и `photos`.
Чтобы оформить другую гонку так же: добавь ей `chars` и `photos`, положи фото в `img/tachki/` и вырезанные машины
в `img/tachki/c_имя.webp`, добавь персонажа в `TKC`. Выбор персонажей игроками хранится в `S.tk.pk`.
