# Рулетка выбора машин — настройка скорости

Замените только файл `js/home.js`.

Анимация занимает около 6,7 секунды: первые 1,7 секунды — быстрый прокрут, затем 5 секунд — равномерное очень медленное продвижение. В медленной фазе указатель проходит одну карточку примерно за секунду и останавливается на выбранной машине.
