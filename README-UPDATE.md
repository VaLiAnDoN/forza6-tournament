# Таблицы времени гонок

Замените в проекте:
- `js/tachki-races.js`
- `js/events.js`
- `style.css`

На странице каждой гонки появился блок «Время гонок». Администратор создаёт заезды и может переименовывать или удалять их. В таблице задаётся время каждого игрока в формате `м:сс,ммм`; можно указать `НФ`. Места пересчитываются автоматически, а введённые заезды остаются в истории этой гонки.
