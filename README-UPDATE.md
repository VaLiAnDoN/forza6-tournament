# Обновление раскладки «Тачки»

Замените файлы `js/tachki-races.js`, `js/events.js` и `style.css`.

- Карточки машин вынесены на левую и правую стороны экрана и увеличены.
- Все изображения машин приведены к одной видимой высоте, поэтому карточки стоят ровно.
- Центральная колонка расширена и получила металлическую панель данных трассы, блок участников и полноценную гоночную таблицу.
- В гоночной таблице есть вкладки заездов, автоматические места по времени, ввод времени/НФ и добавление/удаление заездов для администратора.
