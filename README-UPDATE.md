# Обновление: тайминг рулетки машин

Замените в репозитории:
- js/home.js
- style.css

## Что изменилось
Рулетка машин (горизонтальная лента карточек) теперь крутится по сценарию:
1. 1 секунда — разгон
2. 1 секунда — движение на максимальной скорости
3. 1–2 секунды (случайно) — замедление
4. 1.5–2 секунды (случайно) — очень медленное движение перед остановкой

Итоговая длительность кручения — примерно от 4.5 до 6 секунд, каждый раз разная.

Дополнительно: примерно в половине случаев лента сначала проскакивает мимо итоговой машины
на 1–2 карточки вперёд, а затем медленно откатывается назад и останавливается точно на выигранной
машине — для эффекта азарта и неожиданности.

Анимация теперь управляется через JavaScript (requestAnimationFrame), а не через CSS transition,
поэтому тайминг гибко настраивается и может включать обратный откат.
