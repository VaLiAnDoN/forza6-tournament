# Файлы для папки img/tachki

Поместите файлы в папку `img/tachki/` с НИЖНИМ регистром в именах:

- `c_mcqueen.webp` — Молния Маккуин
- `c_mater.webp` — Мэтр
- `c_cruz.webp` — Круз Рамирес
- `c_fillmore.webp` — Филмор
- `c_sarge.webp` — Сержант
- `c_doc.webp` — Док Хадсон
- `track1.jpg` — фон трассы №1
- `track2.jpg` — фон трассы №2
- `track3.jpg` — фон трассы №3
- `cars-logo.png` — логотип Cars (необязательно для текущей страницы)

Важно: GitHub Pages различает регистр букв. Например, `C_McQueen.webp`, `track1.JPG` или `c_doc.png` не совпадут с путём в JavaScript.

В архиве находятся обновлённые исходники. Изображения не включены, поскольку в текущем чате они были присланы как иллюстрации, а не как исходные файлы проекта с доступными именами и расширениями.
